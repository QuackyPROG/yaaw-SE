# Inspect contract

## Purpose
Independently test the implementation against the exact accepted contract before style or memory can influence acceptance.

## Inputs
Exact current ticket/spec/product/ENG references, admitted repository diff/state, migration/compatibility requirements, and required evidence.

## Checks
Check missing/partial requirements, wrong behavior, scope creep/unrequested behavior, failure-path mismatch, and migration/compatibility mismatch. Every finding cites the exact contract source and current evidence.

## Output
Contract-lens observations only; no lifecycle mutation and no fix authorship.
