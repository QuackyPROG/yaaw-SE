# Durable memory rules

1. Conversation is never the only location of an accepted decision.
2. Record accepted product/engineering decisions before another question round.
3. Every accepted artifact carries machine-readable identity/revision metadata.
4. Keep task-specific mistakes in ticket/review history.
5. Promote only reusable project invariants into canonical Planner-owned `docs/rules/**`; never create a parallel rules root under `.yaaw/`.
6. Preserve superseded/stale artifacts; invalidate their authority instead of deleting history.
7. A fresh context unable to continue from exact handoff + canonical artifacts indicates incomplete documentation/dispatch context.
8. Learned project memory is advisory acceleration only; it never replaces the durable artifacts above.
