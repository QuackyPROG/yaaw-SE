# Expertise: frontend-design

Provides specialist guidance only; grants no authority.

Signals: UI, layout, component, responsive, interaction, accessibility.

Planner: define interaction states, responsive behavior, component boundaries, accessibility constraints, and acceptance conditions.

Implementer: preserve design-system conventions, keyboard/focus semantics, state feedback, responsive behavior, and existing component patterns.

Reviewer: verify behavior across states and viewport constraints, semantics, keyboard/focus behavior, labels, error/empty/loading states, and regressions.
