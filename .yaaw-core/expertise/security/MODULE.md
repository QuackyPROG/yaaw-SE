# Expertise: security

Signals: authentication, authorization, permissions, secrets, untrusted input, sensitive data, public interfaces.

Planner: identify trust boundaries, abuse cases, authorization ownership, secret/data constraints, and security acceptance.

Implementer: validate at trust boundaries, enforce authorization server-side, avoid secret leakage, preserve least privilege, and follow project primitives.

Reviewer: inspect bypass paths, privilege escalation, injection/input handling, secret exposure, unsafe defaults, and missing negative tests.
